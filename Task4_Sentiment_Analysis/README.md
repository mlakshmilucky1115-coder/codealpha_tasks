# CodeAlpha Sentiment Analysis Project

## CodeAlpha Data Analytics Internship - Task 4

This project performs sentiment analysis on Amazon customer reviews using Python and Natural Language Processing (NLP).

## Project Objective

The objective of this project is to analyze customer reviews and classify them into positive, negative, and neutral sentiments.

The project also uses VADER (Valence Aware Dictionary and sEntiment Reasoner) to calculate sentiment scores from the review text.

## Dataset

The dataset contains Amazon customer reviews with the following columns:

- `sentiments`
- `cleaned_review`
- `cleaned_review_length`
- `review_score`

The original dataset contained 17,340 rows.

During data cleaning:

- 3 reviews with missing review text were removed.
- 1,347 duplicate rows were removed.
- Final dataset used for analysis: 15,990 reviews.

## Technologies Used

- Python
- Pandas
- NLTK
- VADER Sentiment Analyzer
- Matplotlib
- Seaborn

## Data Cleaning

The following preprocessing steps were performed:

1. Loaded the CSV dataset using Pandas.
2. Checked the dataset shape and columns.
3. Checked for missing values.
4. Removed reviews with missing text.
5. Converted review text to string format.
6. Checked for duplicate rows.
7. Removed duplicate rows.

## Sentiment Analysis

VADER sentiment analysis was applied to the cleaned review text.

VADER generates a compound sentiment score between -1 and +1.

The sentiment classification used in this project is:

- Compound score >= 0.05: Positive
- Compound score <= -0.05: Negative
- Between -0.05 and 0.05: Neutral
